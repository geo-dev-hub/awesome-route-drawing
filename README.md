# Contributing to Awesome Route Drawing Tools

Contributions are welcome! Please read this document to ensure your pull request is accepted quickly.

## What We Are Looking For
- Tools that specifically help with drawing, plotting, or snapping routes to road networks.
- Open-source libraries, web applications, or desktop tools that solve real mapping UX problems.
- Clear, objective descriptions of the tool's strengths and weaknesses.

## How to Add a Tool
1. Fork this repository.
2. Add your tool to the most appropriate section in the `README.md`.
3. Keep the description concise (under 100 words) and objective.
4. Submit a Pull Request with a brief explanation of why this tool belongs on the list.

Thank you for helping keep this list high-quality and useful for the geospatial community!
